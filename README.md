# 노지 및 시설재배 수확 로봇 플랫폼 개발 

## 프로젝트 개요

**요약 설명**: 경기도경제과학진흥원 사업명은 2024경기도 기술개발사업 이며 과제명은 노지 및 시설재배 수확 로봇 플랫폼 개발이다. 노지와 시설 재배 환경에서 고추를 인식하고 수확하는 자동화 로봇 플랫폼 개발. YOLO 기반 비전 인식으로 고추 줄기 위치를 검출하고, 뎁스 정보를 활용한 매니퓰레이터 제어를 통해 안전한 절단 및 파지 수행.
- **기간**: 2025.03.11 ~ 2025.04.23
- **참여 인원**: 주관기간(전경일 상무 연구책임자 - 모빌리티 개발, 이영수 차장 - 그리퍼 설계, 박상현 - 수확용 로봇 시스템 개발), 공동기관(한양대학교 강민성 교수님 연구실-영상인식모델 개발)
- **사용 기술**: Python, MoveIt, YOLO, 자사의 산업용 매니퓰레이터 Robo003, D435, D405
- **프로젝트 목적**: 노지와 시설 재배 환경 모두에서 효과적인 작물을 수확할 수 있는 로봇 플랫폼을 개발 (적용 작물 : 고추). 이를 통해 농업 노동력 부족 문제를 해결하고, 노지 및 시설 환경의 다양한 조건에서도 안정적인 무인 수확 시스템을 구현하여 생산성 향상을 목표로 함.
- **결과물**: 정량적 목표를 모두 성공적으로 이루며 시연까지 완료하였고 사업화를 위해 추가 개발 진행중
